# CareerPilot 全职业岗位分析器

本项目是一个本地优先运行的求职分析工具，用来完成岗位判断、批量筛选、招聘监测、简历匹配、定制改写、缺口分析、投递管理和面试整理。

## 主要功能

- 岗位工作台：支持单条 JD 判断、批量 JD 分析、行业招聘监测。
- 求职目标卡：目标行业与方向合并为一个选择框，直接参与匹配评分。
- 一键网页采集：在已登录招聘页面一键采集，自动识别列表页或详情页，并同步回 CareerPilot。
- 批量导入：支持粘贴文本、上传 PDF / DOCX / TXT / HTML / Excel / 图片，以及公开链接抓取。
- 简历工作台：支持结构化读取、匹配分析、定制简历、不足清单。
- 求职决策：支持 Offer 预测、今日队列、投递状态管理。
- 面试与报告：支持面经提炼、问题整理、导出投递包。

## 一键网页采集

CareerPilot 现在统一使用 `一键网页采集`。

使用方式：

1. 登录招聘网站。
2. 打开 CareerPilot。
3. 在侧边栏或导入区域找到 `一键网页采集`。
4. 把 `加入书签栏：一键采集` 拖到浏览器书签栏。
5. 回到招聘页面点击这个书签。
6. 回到 CareerPilot，点击 `同步采集结果`。

采集规则：

- 列表页：自动滚动、尝试翻页、补抓详情页。
- 详情页：直接采当前岗位。
- 采集结果会进入 `CareerPilot_JD/YYYY-MM-DD/` 或当前账号的云端采集目录。

## 批量分析建议

推荐流程：

1. 先设置求职目标和当前简历。
2. 用 `一键网页采集` 从招聘网站带回岗位。
3. 在 `批量 JD 分析` 中同步采集结果。
4. 用一键视图筛出高优先级岗位。
5. 把目标岗位加入今日队列，再进入简历工作台改写。

## 说明

- 本地数据默认保存在 `careerpilot.db`。
- 云端采集上传默认使用 `/api/capture-upload`。
- 公开链接抓取支持并发抓取；遇到登录、验证码或强风控页面时，优先使用 `一键网页采集`。
- 图片 OCR 默认使用软件内置识别引擎；如遇极端复杂截图，建议优先上传更清晰的原图或直接粘贴文本。
